## 🎵 Spotify Statistics

A modern web application that analyzes and visualizes a user’s Spotify listening data, displaying top artists, tracks, albums, and playlists across different time ranges.

Built using React and powered by the Spotify Web API.

## 🛠 Tech Stack

- React

- React Router

- Axios

- Netlify Functions (for secure token handling)

- Styled-Components

- Spotify REST API

## ✨ Features

- Spotify OAuth authentication

- View Top Artists (short-term, medium-term, long-term)

- View Top Tracks

- View Top Albums

## 📝 What This Project Demonstrates

- OAuth authentication flow handling

- Secure API calls using serverless functions

- Token management & refresh logic

- Working with third-party REST APIs

- Dynamic data rendering with React

- Route-based page architecture

## 🔗 How It Works

Users log in with their Spotify account. After authentication, the app fetches listening data from Spotify’s REST API and displays personalized insights in a clean and structured format.
